A kind, funny fortune for a houseplant, written for the
[Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9)
competition on [make.fun](https://make.fun).

## The fortune

> You will grow exactly where they said you would not — then outgrow the pot they gave you.

## How it works

`main.py` writes that single line (89 characters, within the 120-character
limit) to `/output/entry.txt`, after validating it is non-empty, a single
line, and no longer than 120 characters.

```sh
python3 main.py
cat /output/entry.txt
```
